**⚙️ Adaopte - Backend API**
C'est l'API robuste de la plateforme Adaopte. Ce backend assure la gestion des données via un ORM performant et une base de données relationnelle sécurisée.

🔗 **Architecture Fullstack**
Ce dépôt est la partie serveur du projet.

**Frontend :** 
API Live (Vercel) : 
🛠️ Stack Technique
Runtime : Node.js
Framework : Express.js
Base de données : PostgreSQL (hébergé sur Neon)
ORM : Prisma

**Déploiement : ** Vercel (Serverless Functions)

✨ **Fonctionnalités Backend**
- Gestion du catalogue : Endpoints pour la récupération filtrée des animaux (chiens, chats, lapins).
- Modélisation des données : Schémas Prisma optimisés pour les relations entre refuges et animaux.
- Performance : Requêtes SQL optimisées via l'ORM Prisma.
- Sécurité : Configuration des CORS pour autoriser uniquement les requêtes du frontend officiel.

🚀 Installation Locale
- Cloner le dépôt
- Installer les dépendances
- Configuration de la base de données
- Créez un fichier .env à la racine et ajoutez votre chaîne de connexion Neon :
- Synchroniser Prisma
- Lancer le serveur
